SOCCER GLOBAL RANKING

The SOCCER GLOBAL RANKING is not just a spreadsheet. It is a complete global football intelligence platform.

Each club contains dozens of meticulously calculated variables:

  • N# = Global Club Position
  • Country
  • State / Province
  • City
  • Short Name
  • Full Name
  • TI = Total Titles Index
  • CELOR = Exclusive Country ELO Rating System
  • WELOR = Exclusive Wellington ELO Rating System
  • SGRP = Exclusive Global Football Club Scoring System
  • PE = Points Earned
  • G / W / D / L = Games / Wins / Draws / Losses
  • GF / GA / GD = Goals For / Goals Against / Goal Difference
  • ACV (€) = Approximate Squad Market Value
  • MC1 = Continental Weighting Multiplier
  • MC2 = National Weighting Multiplier

Everything integrated into an exclusive worldwide methodology.
